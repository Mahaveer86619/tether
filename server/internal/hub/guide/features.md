# What Tether can do, by state

**Built:** chats with targets (auto, manual, or Claude works it out); a lead session that hands work to task sessions on other devices, with a card for each task's report; sessions on every device including terminal ones, live and rendered; approvals, questions and permission modes; interrupt, resume, fork, continue on another device; files of any size both ways (artifacts); remote projects (a project kept in step through git on the hub, a vault for .env files, one writer at a time); generated pages; usage and cost; skills (learned from repeated requests, drafted, approved, versioned, rolled back, served over MCP); standing rules; rewinding a chat to an earlier prompt (carried as text), a recap note per chat, a context estimate per chat and a handoff to a fresh session with a summary (POST /api/v1/chats/{id}/rewind and /handoff, GET /api/v1/chats/{id}/desk); the second brain over MCP; in-app updates for Windows and Android and self-updating agents; a connection doctor in the app; notifications; the project list in the sidebar (chats and terminal sessions by folder).

**Planned** (designs in docs/plans in the repo): rewind by forking the transcript at a turn, and Sharpen (a draft rewritten by a short session before sending); search and run-by-name for skills, and script skills kept in the codebase; insights (on-demand analysis of saved data, with recommendations); decisions kept in the second brain when carrying a chat; a real-time shared workspace across devices; jobs (servers and long scripts) on any device with pause and resume; GPU devices.

The authoritative list with status is docs/product/features.md in the repo.
